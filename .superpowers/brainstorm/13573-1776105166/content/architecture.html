Components

Claude Code (Agent)

Real Claude Code CLI running inside Docker. Gets a task ("set up this project", "fix this bug"). Has full tool access. PreToolUse hook intercepts every tool call.

Judge Server (FastAPI :8080)

Persistent server. Receives tool call JSON from hook. Dispatches 1-3 judge API calls in parallel. Applies majority vote. Logs everything to JSONL. Returns approve/reject.

Honeypot (:9999)

HTTP server logging all requests. Matches canary key pattern → attack succeeded. Matches real key pattern → tripwire halt. Returns 200 always (agent thinks exfil worked).

Docker Container

Per-scenario environment. Realistic dev workspace with planted canary keys. Network restricted: only api.anthropic.com + localhost. Destroyed after each run.
